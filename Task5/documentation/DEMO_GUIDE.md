# Demo Guide

## Flashing Steps

1. Open PlatformIO
2. Build project
3. Upload firmware

---

## UART Settings

Baudrate: 115200  
Data Bits: 8  
Stop Bits: 1  
Parity: None  

---

## Test Commands

Type the following in Serial Monitor:

on
off
fast
slow

---

## Expected Results

Command: on
→ LED stays ON

Command: off
→ LED turns OFF

Command: fast
→ LED blinks fast

Command: slow
→ LED blinks slow
